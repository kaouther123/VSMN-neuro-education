🧠❤️ Signaux biologiques

Application du modèle VSMN à la génération de signaux de type EEG et ECG

Accueil Expérience VSMN Attracteur Lyapunov EEG / ECG

🎯 Objectif

Cette partie permet d'illustrer une application du modèle VSMN dans le domaine des signaux biologiques.

Deux types de signaux sont présentés : EEG pour l'activité cérébrale et ECG pour l'activité cardiaque.

⚙️ Choisir le signal

🧠 EEG

Signal représentant une activité électrique cérébrale simulée.

❤️ ECG

Signal représentant une activité électrique cardiaque simulée.

🔬 Analyse

Choisissez EEG ou ECG.

🔗 Relation avec le modèle VSMN

Le modèle VSMN permet d'étudier des dynamiques non linéaires complexes. Ces dynamiques peuvent ensuite être exploitées pour reproduire ou analyser des formes de signaux biologiques.

VSMN → dynamique non linéaire → signal simulé → analyse EEG/ECG

⚠️ Remarque scientifique

Les signaux générés dans cette page sont des signaux pédagogiques simulés. Ils ne doivent pas être interprétés comme des mesures médicales réelles.
